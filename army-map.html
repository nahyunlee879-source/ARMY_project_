"전 세계 ARMY가 함께 보랏빛 바다를 만드는 실시간 인터랙티브 맵."

BTS의 팬덤 ARMY는 전 세계에 걸쳐 있습니다. 신곡 발매나 컴백 시즌마다 "스밍(스트리밍)" 캠페인이 펼쳐지는데, 이 프로젝트는 그 집단적 에너지를 시각화합니다. 참가자가 버튼을 누를 때마다 자신의 도시에 보라색 빛이 번지고, 전 세계 지도가 보랏빛으로 채워집니다.

HTML Canvas API만으로 구현한 실시간 파티클 시스템, 별이 빛나는 우주 배경, 리플 이펙트, 도시별 글로우 효과 — 모두 외부 라이브러리 없이 순수 Vanilla JS로 작동합니다. 디자인 방향성: 우주에 떠있는 지구, 아미의 보라색이 물들어가는 순간.

Process

01

Concept

팬덤의 집단적 에너지를 시각화하는 방법 탐구. "스밍"이라는 행위를 단순 숫자가 아닌 지리적·감각적 경험으로 표현하고자 했습니다.

02

World Map

SVG 경로 없이 Canvas API로 대륙 폴리곤을 직접 그린 저해상도 세계 지도. Equirectangular projection으로 위경도를 픽셀 좌표로 변환.

03

Particle System

클릭당 최대 52개 파티클 생성. 물리 시뮬레이션(속도, 감쇠, 중력)과 Radial Gradient 기반 도시 글로우 시스템 구현.

04

UX Details

Geolocation API로 사용자 위치 자동 감지, 리더보드 실시간 업데이트, 마일스톤 토스트 알림, 자동 시뮬레이션으로 지도에 생동감 부여.

Features

🌍

Live World Map

Canvas API로 직접 그린 세계 지도. 25개 주요 도시에 인터랙티브 클릭 포인트와 pulse ring 애니메이션.

✨

Particle System

클릭마다 방사형 파티클 버스트 + 리플 웨이브. HSL 색상 범위로 자연스러운 보라색 스펙트럼 표현.

💜

City Glow System

클릭이 쌓일수록 도시 주변 글로우가 강해지는 Radial Gradient 시스템. 시간이 지나면 천천히 감쇠.

📍

Geolocation

Geolocation API로 사용자의 현재 위치를 감지해 가장 가까운 도시를 자동 선택. 권한 거부 시 서울로 폴백.

🏆

Live Leaderboard

실시간 도시 순위 업데이트. Progress bar로 1위 대비 상대적 비율 시각화. 금·은·동 배지 시스템.

🔔

Toast Notifications

마일스톤 달성(10, 50, 100…) 시 토스트 알림. 2위가 1위를 추격할 때 라이벌 알림 자동 생성.
